## Slide 01 — IMPACTO · EDITORIAL_FASHION

```
visualConcept: {
  topic: "Primeira impressão digital",

  visualContrast: "tipografia de marca × interface real de negócio",

  palette: "paper-ink + signal-red (1 detalhe)",
  composition: "wordmark sangrando + browser ocluindo pela direita"
}
```

1. Ideia: impressão precede a leitura.  
2. Metáfora: palavra-gigante = fachada; browser = vitrine.  
3. Objeto: navegador com site de cafeteria.  
4. Cenário: pôster fashion monocromático.  
5. Contraste: tipografia de campanha × interface comercial.  
6. Sem texto menor: ainda se lê “IMPRESSÃO” + janela de site.

## Slide 04 — PRINCÍPIOS · NEO_Y2K_MODULAR (controlado)

```
visualConcept: {
  topic: "Clareza · Cuidado · Direção",
  mainIdea: "Três sinais que constroem confiança — cada um com identidade visual própria",
  metaphor: "Três módulos de construção de presença (não dashboard)",
  heroObject: "Três módulos assimétricos: tipografia / fragmento de UI / CTA evidente",
  environment: "Campo ink escuro com energia controlada",
  supportingDetails: ["símbolos geométricos", "lime ≤10%", "magenta pontual", "números 01–03"],
  backgroundPattern: "DotMatrix / hatch leve",
  visualContrast: "energia modular × disciplina tipográfica",
  dominantStyle: "NEO_Y2K_MODULAR",
  palette: "ink + cobalt + lime + red + magenta detalhe",
  composition: "módulos irregulares, cada um com forma diferente — zero cards iguais"
}
```

1. Ideia: três princípios com forma própria.  
2. Metáfora: blocos de construção (não cards SaaS).  
3. Objeto: módulos tipográficos + recorte de UI + seta de ação.  
4. Cenário: painel escuro energético.  
5. Contraste: três identidades visuais distintas no mesmo sistema.  
6. Sem texto longo: CLAREZA / CUIDADO / DIREÇÃO ainda se leem como manifesto.
